# Software Engineering (Design) – Exam Question with CO Mapping

Course: Software Engineering
Topic: Software Design, Architecture, Design Patterns, UI Design
Full Marks: 40 | Time: 1 hour

The questions follow the OBE approach and Bloom's Taxonomy, and are set at the
Knowledge and Understanding levels of the BNQF cognitive domain.

# Course Outcomes

- CO1: Explain basic software design concepts (modularity, coupling, cohesion) and design metrics.
- CO2: Describe software architecture and architectural styles such as MVC.
- CO3: Explain the intent, structure and benefits of GoF design patterns.
- CO4: Describe enterprise application patterns (Domain Model, Data Mapper, ORM, Page/Front Controller).
- CO5: Explain UI design principles and interaction styles.

 Questions

# Part A: Short questions (1 × 10 = 10)

1. Define software design.
2. Which phase describes how software is organized into components: architectural design or detailed design?
3. Coupling is a measure of the ______ among components.
4. Which metric counts the number of classes used by a class?
5. Name two architectural styles.
6. In MVC, which component shows the model in the user interface?
7. Which GoF pattern makes sure a class has only one instance?
8. Which pattern defines a family of algorithms and makes them interchangeable?
9. Data Mapper is also known as which other pattern(s)?
10. Name one basic UI design principle.

# Part B: Brief answers (2 × 5 = 10)

11. What is cohesion? Why do we want high cohesion?
12. Why should we record the reason behind design decisions?
13. What is the difference between Page Controller and Front Controller?
14. State the intent of the Façade pattern.
15. Name two UI interaction styles and describe each in one line.

# Part C: Descriptive (5 × 4 = 20)

16. Explain low coupling and high cohesion with an example. Name one metric for each. (5)
17. Explain the MVC style. What does each part do, and what are the benefits? (5)
18. Explain the Strategy pattern: its intent, structure and benefits. (5)
19. (a) Explain the Data Mapper pattern. Why does it keep objects and the database independent? (3)
    (b) Explain any two UI design principles. (2)
